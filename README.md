# SkyPath: Flight Connection Search Engine

Prototype flight connection search engine — a Node.js/TypeScript/Express backend and a
React/TypeScript/Vite frontend for searching direct and connecting itineraries (up to 2 stops)
between two airports on a given date.

> This README is a work in progress and will be filled in as the project is built (run
> instructions, architecture rationale, tradeoffs, and assumptions).
